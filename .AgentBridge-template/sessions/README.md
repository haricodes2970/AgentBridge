# Sessions

Per-session summaries live here, one Markdown file per session (e.g.
`2026-11-06-1.md`). Each summary should note:

- Goal worked on
- What was completed
- What is in progress / blocked
- Next action (see .AgentBridge/next.md)
- Git state at close (branch, commit)

These are cold-path reference only; the hot path is the four files at the
root of .AgentBridge/.
